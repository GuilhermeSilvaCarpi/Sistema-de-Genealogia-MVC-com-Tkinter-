# Sistema-de-Genealogia-MVC-com-Tkinter-
Um sistema desktop para gerenciamento e visualização de relações familiares, desenvolvido em Python com arquitetura MVC e interface gráfica em Tkinter + ttkbootstrap.  O projeto permite cadastrar pessoas, relacionar pais e mães, pesquisar registros dinamicamente e visualizar uma árvore genealógica recursiva em formato textual.
